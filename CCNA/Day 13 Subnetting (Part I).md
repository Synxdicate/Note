## CIDR
**classless inter-domain routing**
คือไม่สนคลาส จากเดิมที่เป็น classful networking จะได้ไม่เปลืองเลข IP ที่ไม่ได้ใช้
```
class A = /8
class B = /16
class C = /24
```
จากเดิมที่เขียนในรูป dotted decimal อย่าง `255.255.255.0` เป็น `/n`

ถ้าอยากย่อยเองก็ 
$$32-n$$
เมื่อ n = /n

**CIDR Notation**
```
255.255.255.128 = /25 = 126
255.255.255.192 = /26 = 62
255.255.255.224 = /27 = 30
255.255.255.240 = /28 = 14
255.255.255.248 = /29 = 6
255.255.255.252 = /30 = 2
255.255.255.254 = /31 = 0
255.255.255.255 = /32 = -1
```

แล้วแต่จะ optimize มันยังไงว่าจะให้ network ใหญ่เพื่อให้เหลือ host น้อย จะได้ไม่เปลือง host ที่ไม่ได้ใช้
